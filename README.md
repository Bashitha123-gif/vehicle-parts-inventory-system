# Vehicle Parts Inventory Management System

A modern inventory management system for vehicle parts shops.

## Tech Stack

- NestJS
- React
- TypeScript
- PostgreSQL
- Prisma ORM
- Tailwind CSS
- JWT Authentication

## Features

- User Authentication
- Category Management
- Brand Management
- Product Management
- Supplier Management
- Customer Management
- Purchase Management
- Sales (POS)
- Reports
